## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`draw_image.py` draws `entry.png` (1024x1024, Pillow, local build only).
`main.py` is the submitted program: standard library only, it copies
`entry.png` to `/output/entry.png`, deterministically, with no network.
